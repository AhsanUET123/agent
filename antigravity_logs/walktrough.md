# CIRO AI Agent Walkthrough

## Overview
This project is an AI-driven crisis response system that detects, classifies, and responds to events in real-time.

## Workflow
1. Data ingestion
2. LLM classification
3. Event routing
4. Notification dispatch (email/alerts)

## Tech Stack
- Python
- FastAPI
- LLM API
- SMTP email system

## Outcome
Automated crisis detection + response system with real-time alerting.
